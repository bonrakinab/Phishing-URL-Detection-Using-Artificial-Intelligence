Phishing URL Detection Using Artificial Intelligence
Objective: Develop a robust system to detect phishing URLs, enhancing cybersecurity and protecting sensitive data.

Technologies Used: Machine Learning (Random Forest, Decision Tree, Logistic Regression) and Large Language Models (BERT, DistilBERT, TinyBERT).
Dataset: PhiUSIIL dataset with 235,795 samples, split for training, validation, and testing.
Preprocessing: Applied Tfidf vectorization, SMOTE for class balancing, and BERT tokenization for feature extraction.
Key Achievements:
Achieved over 99% precision, recall, and F1-score for top-performing models (BERT and Random Forest).
Designed and implemented a Flask-based user interface for real-time phishing URL detection.
Impact: Enhanced phishing detection accuracy, providing a scalable and user-friendly solution for cybersecurity applications.
